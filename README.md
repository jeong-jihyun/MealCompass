# MealCompass

헬스 커넥트의 걸음 수·수면·심박을 읽고, 폰 안에서 도는 작은 AI(Gemma-3 1B)가
내 주변(1km) 식당 중 오늘 맞는 곳을 골라 주는 안드로이드 앱입니다.

## 개인정보
- 건강 데이터는 폰 안에서만 처리하고, 어디로도 보내지 않습니다.
- 식당 검색을 위해 현재 위치 좌표만 카카오 서버로 전송됩니다.
- 첫 실행 때 동의를 받고, "동의 철회" 버튼으로 저장된 설정과 모델 파일을 지울 수 있습니다.
- 일반 식습관 참고용이며 진단·치료 조언이 아닙니다.

## 설치 (APK를 클라우드에서 빌드)
1. GitHub에 새 저장소를 만들고 이 폴더의 모든 파일을 올립니다 (`.github` 폴더 포함).
2. 저장소의 Actions 탭에서 `Build APK`를 실행하고, 끝나면 `MealCompass-debug-apk`를 받아 압축을 풉니다.
3. `app-debug.apk`를 폰에 옮겨 설치합니다 (출처를 알 수 없는 앱 설치 허용 필요).

## 사용 전 준비
- **헬스 커넥트**: 안드로이드 14 이상은 기본 내장, 그 이하는 스토어에서 Health Connect 앱 설치.
  삼성 헬스 등의 데이터가 헬스 커넥트로 공유되도록 설정되어 있어야 합니다.
- **카카오 REST 키**: developers.kakao.com에서 앱을 만들고 REST API 키를 발급합니다.
  403 응답이 오면 앱 설정에서 카카오맵(로컬) 사용 설정이 필요한지 확인하세요.
- **AI 모델(선택)**: Hugging Face의 litert-community Gemma3-1B-IT 저장소에서 int4 `.task` 파일을
  받아 (약수백 MB, 라이선스 동의 필요) 앱의 ② 버튼으로 선택합니다.
  없으면 간단한 기본 규칙으로 추천합니다.

## 알려진 한계
- 아직 직접 빌드·실행해 보지 못했습니다. 첫 빌드에서 오류가 나면 Actions 로그를 그대로 알려 주세요.
- MediaPipe LLM Inference는 구글이 유지보수 전용으로 분류한 상태입니다.
- 1B 모델은 한국어가 약해서, 목록에서 번호를 고르게 하고 이유 한 줄만 받습니다.
- 헬스 데이터가 없는 항목은 "정보 없음"으로 처리됩니다.
